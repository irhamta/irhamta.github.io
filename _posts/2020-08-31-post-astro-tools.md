## Python stuff

Python offers many advantages for astronomy ([see this overview](https://www.astrobetter.com/wiki/tiki-index.php?page=python)). Some useful packages include:

1. [Astropy](https://docs.astropy.org/en/stable/index.html), which provides tools for working with FITS files, tables, coordinate systems, models, fitting, and units.
2. [Spectral-cube](https://spectral-cube.readthedocs.io/en/latest/) for reading, manipulating, analyzing, and writing data cubes with two positional dimensions and one spectral dimension.
3. [APLpy](https://aplpy.readthedocs.io/en/stable/) (the Astronomical Plotting Library in Python) for producing publication-quality plots of astronomical imaging data.
4. [scikit-learn](https://scikit-learn.org/stable/) for machine learning and predictive data analysis.
5. [lmfit](https://lmfit.github.io/lmfit-py/) for nonlinear optimization and curve-fitting problems.
6. [Photutils](https://photutils.readthedocs.io/en/stable/) for detecting and performing photometry of astronomical sources.

## Reference management

For managing a list of papers, [Mendeley](https://www.mendeley.com/) is a free reference manager. It allows you to sort papers by keyword, produce BibTeX files for LaTeX documents, and annotate PDFs.

## Useful websites

1. arXiv discussions at [Benty-fields](https://www.benty-fields.com/daily_arXiv).
2. Tips and advice for professional astronomers at [AstroBetter](https://www.astrobetter.com/).
3. Astronomy-related job listings at the [AAS Job Register](https://jobregister.aas.org/).
